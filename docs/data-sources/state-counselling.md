# State Counselling Authorities

> Sprint 3.0. Official counselling authority and portal for each state/UT that
> was actually verified. Coverage is **partial** — do not read this as
> India-wide until every state/UT is verified.

## Coverage statement

- **Verified this research pass: 11 states** (see table below).
- **NOT YET VERIFIED: 25 states/UTs** (see full status list).
- Scope dimensions beyond the portal itself (government vs private college
  split, "other" categories such as minority/management/NRI quota) were **not
  individually verified** and are marked NOT VERIFIED rather than assumed.
